# ADR-101 1.0 support matrix

## Decision

| Dependency | Minimum | Notes |
| --- | --- | --- |
| PHP | 8.1 | 8.1–8.4 tested |
| WordPress | 6.2 | Current stable in CI; trunk optional/non-blocking |
| MySQL | 8.0.1 | SKIP LOCKED is mandatory for the MySQL driver |
| MariaDB | 10.6 | SKIP LOCKED available |
| Redis | 6.0 | 7.x primary CI; do not claim 6 if a 6.x job is red |
| PhpRedis | 5.3 recommended | `ext-redis` suggested |
| WooCommerce | not required | HPOS jobs-by-ID tests when present |

PHP 8.1 remains the minimum because WordPress 6.2-era plugin ecosystems still ship it. Raising to 8.2 would be a later minor/major decision, not a silent 1.0 change.
